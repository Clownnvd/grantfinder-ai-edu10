# GrantFinder AI frontend

Next.js 16 + React 19 + Tailwind CSS 4. Giao diện gồm discovery, proposal draft, review queue và data/evaluation dashboard.

```powershell
pnpm install --frozen-lockfile
$env:NEXT_PUBLIC_BFF_URL='http://127.0.0.1:8000'
pnpm dev
```

Theo `AGENTS.md`, mọi thay đổi Next.js phải đối chiếu tài liệu trong `node_modules/next/dist/docs/`.
